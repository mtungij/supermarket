## Changes made
- Cropped to the left 2730×2100 px. This removes a branded snack display in the foreground and a shopper.
- Applied a soft Gaussian blur (radius = width / 300). Price tags, signs and packaging are no longer legible, so no brand or text shows.
- Applied +5% contrast.
- Resized to 768, 1280 and 1920 px wide and saved as WebP (quality 70) plus a JPEG fallback (quality 72, progressive).
- All EXIF metadata, including the phone's GPS position, was removed.

The page draws a navy gradient over the image and uses the same gradient as a fallback if the image fails to load.

AVIF was not produced: the build machine's image library has no AVIF encoder. WebP is supported by all current browsers, and older browsers get the JPEG.
